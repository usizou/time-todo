# Time & To-Do

タイマーと To-Do をまとめたデスクトップアプリです（[Electron](https://www.electronjs.org/) 製）。

## 機能

### カウントダウンタイマー
- 最大 **12 時間**、時 / 分 / 秒で自由に設定
- プリセット（1分・5分・10分・25分・1時間・3時間）
- 終了時にビープ音と OS 通知

### 時刻指定（目標時刻まで）
- 目標時刻（例: 18:00）を指定すると、その時刻までカウントダウン
- 過ぎている時刻を指定した場合は翌日として扱う
- 前回指定した時刻を次回起動時の初期値として復元
- このモードのときは画面下部に「次にアラームが鳴る To-Do」を表示（押すと To-Do タブへ移動）

### 毎正時チャイム
- ON にすると、毎時 XX:00 に音と通知でお知らせ（設定は保存され次回も維持）

### 残り時間の可視化（リング）
- カウントダウン … **総合時間** の円で残り時間を表示
- 時刻まで … **時 / 分 / 秒** の同心円リング（内側ほど速く回り、秒リングで時間の流れを体感）
- 残り10秒で赤く警告

### To-Do
- タスクの追加（入力 + Enter / 追加ボタン）
- 本文はクリックでその場編集（Enter/フォーカスアウトで確定）
- 任意で日付・時刻を指定でき、その日時に音と通知でお知らせ（日時なしのタスクも登録可）
- チェックボックスで完了を切替（完了時は取り消し線 + グレー表示、リストの下部へ移動）
- タスクの削除
- ドラッグ＆ドロップで自由に並べ替え
- 完了したタスクをまとめて削除
- 本文に `#タグ`（例: `資料作成 #仕事 #重要`）を書くと自動でタグ化。上部のタグバーやタスク内のタグをタップで絞り込み（絞り込み中に追加したタスクにはそのタグが自動で付きます）
- 内容は自動保存され、再起動しても残る

### メモ
- 入力するとリストに残るログ形式（新しいものが上、日時付き、削除可）。自動保存され次回も残ります
- **Shift+Enter で追加 / Enter で改行**（または「追加」ボタン）。複数行のメモも書けます（入力欄は内容に応じて高さが伸びます）
- 本文に `#タグ`（例: `資料を確認 #仕事 #重要`）を書くと自動でタグ化。上部のタグバーやメモ内のタグをタップすると、そのタグで絞り込めます（`#タグ` は本文から取り除かれチップ表示になります）
- メモ本文をクリックするとその場で編集できます（Shift+Enter で確定 / Esc で取り消し、`#タグ` を含めて編集するとタグも取り直されます）
- タグで**絞り込み中**に書いたメモには、そのタグが自動で付きます

### リマインダー（⏰ 通知タブ）
- 名前＋時刻を決めて登録すると、その時刻に音＋通知でお知らせ
- 繰り返し：**一回だけ / 毎日 / 平日（月〜金・祝日除く）/ 週末（土日）/ 毎週（曜日を選択）**
- **「平日」は日本の祝日を除外**（内閣府の祝日データを同梱。振替休日・国民の休日も反映）
- 各リマインダーはチェックでオン/オフ、✎で編集、✕で削除。次回発生日時も表示
- スマホでは繰り返し通知を予約するので、アプリを閉じていても鳴ります（デスクトップはアプリ起動中に鳴ります）

### Googleカレンダー表示（📅 アイコン）
- ⚙メニューに GoogleカレンダーのICS URL（設定→カレンダー→「iCal形式の限定公開URL」）を貼ると、その予定を表示できます。**複数カレンダー登録OK**（読み取り専用）
- 時刻までモードの上部に**その日の予定を最大2行**表示（1行目＝終日、2行目＝時間指定。複数あるときは「他◯」）
- タブ右の📅アイコンで**月間カレンダー**を表示。予定のある日にはドット、日付をタップするとその日の予定一覧
- 繰り返し予定（毎日/毎週/毎月/毎年）にも対応（複雑な繰り返しは一部取りこぼす場合あり）

### 共通
- 各モード（時刻まで / カウントダウン）は独立して**同時に稼働**でき、モードを切り替えても止まりません（稼働中はボタンに●印）。既定は「時刻まで」で起動
- **ダーク / ライト**のテーマ切替（⚙メニュー内。設定は保存されます）
- スペースキーで現在モードのスタート / 一時停止
- 上部タブで「タイマー / To-Do / 通知 / メモ」を切替
- **Androidホーム画面ウィジェット**：今日のリマインダーと今日/日付なしの未完了To-Doを2セクションで表示（読み取り専用・タップでアプリを開く）。アプリでデータを更新すると反映されます
- 歯車メニュー（⚙）から To-Do・メモ・カレンダー設定を **CSV で書き出し／読み込み**（別端末への移行用）
  - デスクトップ … ダウンロードフォルダに `time-todo_YYYYMMDD-HHMM.csv`（書き出し日時入り）を保存
  - Android … **共有シート**が開き、Google ドライブ・ファイルアプリ・Gmail などへ保存／送信できます

## 開発

必要環境: [Node.js](https://nodejs.org/)（18以上を推奨）

```bash
# 依存関係のインストール
npm install

# 開発起動
npm start
```

## ビルド（Windows exe の作成）

```bash
npm run dist
```

`dist/` に以下が生成されます:

- `TimeToDo-portable-<version>.exe` … ポータブル版（インストール不要でダブルクリック起動）
- `Time & To-Do Setup <version>.exe` … インストーラー版

> 署名は行っていないため、初回起動時に Windows SmartScreen の警告が出ることがあります。
> その場合は「詳細情報」→「実行」で起動できます。

## 構成

| ファイル | 役割 |
|---|---|
| `main.js` | アプリ本体・ウィンドウ・OS通知・データ保存 |
| `preload.js` | 画面（レンダラー）と本体の安全な橋渡し |
| `src/index.html` | 画面レイアウト（タブ構成） |
| `src/renderer.js` | タイマー・To-Do の動作ロジック |
| `src/style.css` | 見た目 |
| `docs/DESIGN.md` | 技術設計資料 |

## スマートフォン（Android）で使う

Capacitor で Android アプリ(APK)化でき、GitHub Actions（クラウド）でビルドします。
この PC に Android SDK を入れる必要はありません。

手順:

1. このリポジトリを GitHub に push する
2. GitHub の **Actions** タブ →「Build Android APK」→ **Run workflow**（`main` への push でも自動実行）
3. 実行完了後、その run の **Artifacts** から `TimeToDo-android-debug`（APK）をダウンロード
4. APK をスマホに転送し、「提供元不明のアプリ」を許可してインストール

補足:
- 生成されるのはデバッグ版（未署名）です。個人利用向け。
- タイマー終了・毎正時チャイム・タスクのアラームは、OSのスケジュール通知として予約され、
  **アプリを閉じていても指定時刻に通知**されます（初回に通知の許可が必要）。
- スマホ版のデータは端末内（localStorage）に保存され、PC版とは同期しません。

ローカルで Android プロジェクトを更新したいときは:

```bash
npm run sync
```
